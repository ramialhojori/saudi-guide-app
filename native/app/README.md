# تطبيق دليل السعودية (Expo SDK 57)

```bash
npm install
npx expo start                                        # يشتغل من النسخة المدمجة
EXPO_PUBLIC_API_URL=https://… npx expo start          # من السيرفر
npx tsc --noEmit                                      # فحص الأنواع قبل أي تسليم
```

## الشاشات
| المسار | الشاشة |
|---|---|
| `(tabs)/index` | الرئيسية: التحية، البحث، الاختصارات، المدن (8 + باقي الوجهات)، مختارات الأسبوع، الفعاليات، الأخبار |
| `(tabs)/guide` | الدليل: كل المدن والمناطق + بحث + فلتر مدن/مناطق |
| `(tabs)/trip` | رحلتي: الأماكن المحفوظة حسب المدينة، ترتيب، مسار قوقل ماب |
| `(tabs)/events` · `event/[id]` | الفعاليات + التذاكر |
| `(tabs)/more` | روابط وتواصل (اسأل أهل المدينة والكوبونات «قريباً») |
| `city/[id]` | المدينة: أنواع الأماكن + بحث + القائمة |
| `place/[id]` | المكان: الصور، الاتجاهات، اتصال، الموقع، مشاركة، الحفظ |
| `article/[id]` | الخبر |
| `search` | البحث + «قريب مني» (`search?near=1`) |

## قواعد
- الألوان والخطوط من `src/theme/tokens.ts` فقط. الهوية فرائحية: نوزّع الألوان وما نعتمد على البرتقالي لكل شي.
- كل البيانات تمر من `src/lib/content.ts` (السيرفر أو النسخة المدمجة).
- زر الحفظ واحد في كل التطبيق (`HeartButton`) — ما فيه نظامين مثل قودبابر.
- أي مكتبة جديدة: نسخة متوافقة مع SDK 57 من `node_modules/expo/bundledNativeModules.json`.
