# دليل السعودية — التطبيق الأصلي

نسخة أصلية (Native) من تطبيق **دليل السعودية** لآيفون وأندرويد، مبنية بـ Expo.
**لوحة قودبابر تبقى هي مكان إدارة المحتوى** (الأماكن، الفعاليات، الأخبار) والموقع saudi-guide.com،
والتطبيق الجديد يقرأ المحتوى منها عن طريق سيرفر على Cloudflare.

## كيف تمشي البيانات

```
لوحة قودبابر (رامي يضيف وينشر)
        │  مزامنة كل ساعة (واجهة قودبابر الرسمية)
        ▼
سيرفر Cloudflare (Worker + قاعدة D1 + صور R2)
        │  /v1/...  (مرجع: docs/api/API.md)
        ▼
تطبيق Expo (آيفون + أندرويد)
```

- **المحتوى:** يُكتب في قودبابر فقط. السيرفر ينسخ المنشور، ويحذف اللي انحذف أو رجع مسودة.
- **المجتمع** (الحسابات، رحلتي، التقييمات، اسأل أهل المدينة، الكوبونات): في سيرفرنا — المرحلة 2.
- **الإشعارات:** من سيرفرنا عبر Expo Push، تلقائياً عند نشر مكان أو فعالية، وموجّهة حسب مدن المستخدم.

## هيكل المجلد

```
native/
├── app/        التطبيق (React Native + Expo SDK 57 + TypeScript)
├── backend/    السيرفر: Cloudflare Worker + D1 + سكربت تحويل محتوى قودبابر
└── docs/       الخطة، القرارات، مرجع الـAPI
```

## تشغيل سريع

```bash
# السيرفر محلياً
cd backend && npm install && cp wrangler.example.toml wrangler.toml && npx wrangler dev

# التطبيق
cd app && npm install && npx expo start
# لو السيرفر شغال: EXPO_PUBLIC_API_URL=http://localhost:8787 npx expo start
# بدون سيرفر: التطبيق يشتغل من النسخة المدمجة src/data/snapshot.json
```
