# 0001 — تطبيق أصلي بـ Expo

- **الحالة:** معتمد · **التاريخ:** 12 أكتوبر 2026

## السياق
صفحات الكود المخصص في قودبابر وصلت حدودها: تشتغل داخل إطار (iframe)، فطلعت مشاكل مثل روابط المدن في الويب، الحفظ في «مفضلتي» اللي ما توصله «رحلتي»، واهتزاز القوائم. وهدف رامي بناء **مجتمع سعودي** يحتاج حسابات وتفاعل ما تقدر عليه المنصة.

## القرار
نبني التطبيق بـ React Native + Expo (نفس تقنية «شووت» اللي انبنى وانتشر خلال أسبوع).

## النتائج
- تجربة أصلية: خرائط، بدون نت، إشعارات موجّهة، ويدجت لاحقاً.
- نعيد استخدام كود شووت (الدخول، الإشعارات، النقاط).
- الصيانة صارت علينا: تحديث Expo السنوي ومتطلبات المتاجر.
